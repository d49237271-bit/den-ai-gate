# Настройка в браузере

Откройте https://neurogate.nurtech.dev/start — Telegram для первой настройки не нужен.
Выберите Mac или Windows, получите бесплатный ключ по ссылке сервиса и вставьте его
в поле. Ключ скрыт: кнопка с глазом показывает его только по вашему нажатию.

После проверки нажмите «Скопировать» у команды установки и выполните её в Терминале
на Mac или PowerShell на Windows. Команда одноразовая, действует 24 часа и содержит
код доступа к вашим ключам — не пересылайте её. Сам ключ в команде не указан.

Дождитесь `ACCESS GRANTED`, откройте OpenCode и выберите папку проекта. На Windows
добавьте модель neurogate через «+» в списке моделей, как подскажет установщик.

Чтобы добавить ключи после установки, выполните `neurogate add` — откроется локальная
страница на вашем компьютере. Сохранённый ключ подхватывается сразу. Сайт не может
изменять локальные настройки напрямую.

Видеопоказ доступен на https://neurogate.nurtech.dev/#video. В записи показан путь
через Telegram; настройка через браузер выдаёт такую же команду установки.

## Для сопровождения

Видео и обложка хранятся вне Git и Docker-образа в постоянном томе бота:
`/data/media/neurogate-tutorial.mp4` и `/data/media/neurogate-tutorial.jpg`.
Папку можно изменить переменной `BOT_MEDIA_DIR`. Маршрут `/media/` отдаёт только
эти два файла; MP4 поддерживает запросы Range для перемотки. При переносе сервиса
нужно перенести и медиафайлы. Исходник — предоставленное владельцем видео 6:47;
в версии для сайта скрыт API-ключ в эпизоде создания и отправки ключа.
