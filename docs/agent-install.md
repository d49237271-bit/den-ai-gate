# Установка шлюза Ден.AI: инструкция для ИИ-агента

> Этот файл написан для ИИ-агента (Claude Code и подобных). Человек дал ссылку на него и попросил
> установить шлюз. Выполни шаги по порядку, говори с человеком по-русски и коротко.

**Что это.** Локальный шлюз к бесплатным нейросетям. После установки в Claude Code появляется
команда `/free`: Claude планирует и проверяет, код пишет бесплатная модель.

## Правила

- **Ключи API ты не видишь и не вводишь.** Не проси человека прислать ключ в этот чат и не читай
  файл `.env`. Ключ человек вставляет сам на локальной странице. Попал в чат — не используй его
  и предложи создать новый.
- Ничего не устанавливай кроме того, что делает установщик ниже.
- Если шаг упал, покажи человеку последние строки вывода и что ты предлагаешь.

## Шаг 1. Установка

macOS / Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/d49237271-bit/den-ai-gate/stable/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/d49237271-bit/den-ai-gate/stable/install.ps1 | iex
```

Без интерактивного терминала установщик сам пропустит мастер ключей. Команда идёт 2–3 минуты.

## Шаг 2. Ключ

Выполни `~/.local/bin/neurogate add`. Откроется страница на компьютере человека. Попроси его
получить ключ по кнопке, вставить на странице и нажать «Подключить». Из России и Беларуси Gemini
работает только с VPN на весь компьютер. Запасной вариант: OpenRouter.

## Шаг 3. Проверка

```bash
~/.local/bin/neurogate doctor
```

## Шаг 4. Итог человеку

Скажи коротко:

- в новом окне Claude Code работает `/free <задача>`;
- кончился лимит Claude: `claude-free`, внутри бесплатные модели;
- бесплатные сервисы могут использовать запросы для обучения: чужой код и секреты туда не отправлять.
